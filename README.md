# RutinaFit

Generador de rutinas de gimnasio con IA, personalizadas según peso, altura, objetivo, deporte y días disponibles.

Proyecto Final - Tecnicatura en Programación.

## Objetivo
Permitir que cualquier persona obtenga una rutina de entrenamiento adaptada a sus necesidades, de forma gratuita.

## Requisitos

### Requisitos funcionales
- **RF1:** el usuario completa un formulario con peso, altura, edad, objetivo, deporte, nivel y días disponibles.
- **RF2:** el sistema valida los datos ingresados (rangos, campos obligatorios).
- **RF3:** el sistema genera una rutina semanal según el perfil (ejercicios, series, repeticiones y descanso).
- **RF4:** la rutina muestra cada ejercicio con su imagen o gif.
- **RF5:** el usuario puede regenerar un ejercicio individual.
- **RF6:** el sistema incluye calentamiento según el día de entrenamiento.
- **RF7:** el usuario puede registrar su progreso (pesos y repeticiones).
- **RF8:** el usuario puede ver el historial de rutinas generadas.
- **RF9:** el usuario puede compartir su rutina mediante un enlace.
- **RF10:** la aplicación está disponible en español, inglés e italiano.
- **RF11:** el usuario puede instalar la app (PWA) y recibir recordatorios de entrenamiento.

### Requisitos no funcionales
- **RNF1 Usabilidad:** interfaz clara, que se entienda sin instrucciones.
- **RNF2 Responsive:** funciona bien en celular, tablet y escritorio.
- **RNF3 Rendimiento:** la rutina se genera en menos de 3 segundos.
- **RNF4 Accesibilidad:** contraste adecuado, etiquetas en formularios y navegación con teclado.
- **RNF5 Compatibilidad:** funciona en las versiones actuales de Chrome, Firefox, Edge y Safari.
- **RNF6 Mantenibilidad:** código organizado, comentado y versionado en GitHub.
- **RNF7 Privacidad:** no se piden datos sensibles innecesarios y se avisa cómo se usan los datos.
